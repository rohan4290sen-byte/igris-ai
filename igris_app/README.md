# ⚡ IGRIS - Shadow Knight AI Assistant (Android App)

Dedicated Native Android App with a **Floating Shadow Flame (Glowing Overlay)** on your screen that controls your entire phone, plays YouTube, calls contacts, sends emails, launches any app, and talks back in a deep badass voice powered by Gemini 2.5 Flash.

---

## 🌟 Key Features

1. **Floating Shadow Flame Overlay:**
   - Always visible on top of any app on your phone.
   - Drag to reposition anywhere.
   - Tap to wake Igris.

2. **Deep Badass Voice (TTS):**
   - Tuned pitch and rate for an authoritative, loyal Shadow Knight voice.
   - Responses in Hinglish (*"At your command, Boss."*, *"Yes Boss, task completed."*).

3. **Dynamic All-Apps Launcher:**
   - Can find and launch **any app** currently installed or newly downloaded from the Play Store using `PackageManager`.

4. **Phone Automation:**
   - **Direct Calling:** *"Rahul ko call lagao"* or dial numbers.
   - **YouTube Playback:** *"YouTube par Solo Leveling theme song chalao"*.
   - **Flashlight (Torch):** *"Torch on/off karo"*.
   - **Battery Status:** *"Battery kitni hai Boss?"*.
   - **Email:** Drafts and prepares emails instantly.

## 📱 How to Get the APK on Your Phone

### Method 1: 1-Click Cloud Build (Free via GitHub Actions)
1. Push this folder to a free GitHub repository.
2. Go to the **Actions** tab on GitHub.
3. The workflow automatically builds `Igris-AI-App.apk`.
4. Download the APK directly onto your phone and install it!

### Method 2: Local Android Studio Build
1. Open **Android Studio**.
2. Click **Open** and select this directory: `igris_app`.
3. In the top menu, click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Once completed, transfer the generated `app-debug.apk` to your phone and install!
